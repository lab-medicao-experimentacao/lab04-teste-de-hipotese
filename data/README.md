# Dados reais

Salve nesta pasta a amostra real usada pelo grupo, preferencialmente em CSV. A coleta e o cenário ainda serão definidos.

Para o par P2 (t pareado × Wilcoxon pareado), preserve o pareamento: cada linha deve identificar a mesma unidade observada nas duas condições. Documente o significado das condições e a unidade das medições.

Ao incluir a amostra, registre aqui:

- Fonte dos dados, com URL ou identificação do projeto e versão utilizados.
- Data, procedimento de coleta e, quando pertinente, características da máquina e do ambiente de execução.
- Quantidade de pares e significado de cada coluna, incluindo unidades.
- Tratamento de valores ausentes, execuções com falha ou observações excluídas, com justificativa.

Os parâmetros da simulação deverão ser escolhidos a partir dessa amostra e explicados no dashboard. O código de geração dos dados simulados ficará em `src/` e deverá usar semente fixa.
